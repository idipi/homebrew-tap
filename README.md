# homebrew-tap

My personal Homebrew tap.

```sh
brew tap idipi/tap
```

## Formulae

- [`buckle`](https://github.com/idipi/buckle) - Buckle up your AI agents on macOS.
  Kernel-level Seatbelt sandbox and hardware capability broker.

  ```sh
  brew install buckle
  ```

- [`quietupdate`](https://github.com/idipi/quietupdate) - quietly track
  macOS security updates without Apple's major-upgrade nag.

  ```sh
  brew install quietupdate
  ```
