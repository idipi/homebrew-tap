# homebrew-tap

My personal Homebrew tap.

```sh
brew tap idipi/tap
```

## Formulae

- [`agent-sandbox`](https://github.com/idipi/macos-agent-sandbox) - Hardened
  kernel-level Seatbelt sandbox and hardware capability broker for AI coding agents.

  ```sh
  brew install agent-sandbox
  ```

- [`quietupdate`](https://github.com/idipi/quietupdate) - quietly track
  macOS security updates without Apple's major-upgrade nag.

  ```sh
  brew install quietupdate
  ```
